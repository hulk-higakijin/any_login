# AnyLogin

A development-only account switcher for Phoenix applications. AnyLogin provides
the runtime and injects its integration into an existing Phoenix application.

## Quick Start

Add AnyLogin to your Phoenix application's `mix.exs`:

```elixir
def deps do
  [
    {:any_login, "~> 0.1.0"}
  ]
end
```

Fetch dependencies and run the generator from the Phoenix application:

```sh
mix deps.get
mix phx.gen.any_login Accounts users
```

`Accounts` is the existing context module and `users` is the Ecto table name.
The application must expose `UserAuth.log_in_user/2`, as generated by
`mix phx.gen.auth`.

The generator updates the application automatically:

- configures AnyLogin with the repository, user schema, and authentication module
- adds `AnyLogin.Plug` to the browser pipeline
- adds the account-switcher route under `/dev`
- renders `AnyLogin.Component` in the root layout

Start the application normally:

```sh
mix phx.server
```

When `:dev_routes` is enabled, the account switcher appears in the bottom-left
corner.

## Options

Pass custom web and authentication modules when the defaults do not apply:

```sh
mix phx.gen.any_login Accounts users --web MyAppWeb --auth MyAppWeb.UserAuth
```

For a non-standard schema location, pass its full module name explicitly:

```sh
mix phx.gen.any_login Accounts users --schema MyApp.Accounts.User
```

The integration is idempotent, so rerunning the generator does not duplicate
changes. Pass `--no-inject` to print manual integration instructions without
modifying the application.

## Generated Integration

The generator adds this development configuration:

```elixir
config :any_login,
  repo: MyApp.Repo,
  schema: MyApp.Accounts.User,
  auth: MyAppWeb.UserAuth
```

It adds the following Plug to the browser pipeline:

```elixir
plug AnyLogin.Plug,
  enabled: Application.compile_env(:my_app, :dev_routes, false)
```

It adds the development-only route:

```elixir
if Application.compile_env(:my_app, :dev_routes, false) do
  scope "/dev", AnyLogin do
    pipe_through :browser

    post "/account-switcher", Controller, :switch
  end
end
```

It renders the shared component in the root layout:

```heex
<%= if assigns[:any_login_enabled] do %>
  <AnyLogin.Component.account_switcher
    users={@any_login_users}
    current_user={assigns[:current_scope] && assigns[:current_scope].user}
    return_to={@any_login_return_to}
  />
<% end %>
```

## Local Development

To test an unpublished local checkout instead of the Hex release, use a path
dependency:

```elixir
{:any_login, path: "../any_login"}
```

Documentation is published at <https://hexdocs.pm/any_login>.
